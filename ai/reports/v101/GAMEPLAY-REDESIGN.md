# V10.1 核心玩法与战斗 UI 重构（GAMEPLAY-REDESIGN / BATTLE-UI / GROWTH-UI）

## 一、核心循环（保持并加强）

```
经营(工作/摸鱼/修炼/社交) → 资源 → 招募员工/调卡组 → 挑战项目
→ 卡牌战斗(策略) → 击败 Boss → 装备+卡牌奖励 → 强化角色 → 晋升 → 新章节
```

本轮改动全部服务于这条循环，不新增孤立系统：

| 环节 | 加强 | 所属报告 |
|---|---|---|
| 经营→战斗联动 | 装备词条→卡牌伤害乘数（既有 tagMul）；疲劳→攻击惩罚（既有）；宗门/命格 modifiers（既有）保留 | — |
| 卡组调整 | 净化移除 + 升级 + 流派倾向提示 | CARD-BATTLE-REDESIGN.md |
| 挑战项目 | 敌人行为类型化 → 每波打法不同 | CARD-BATTLE-REDESIGN.md |
| Boss | 5 大独特战术 + 打断窗口 | BOSS-REDESIGN.md |
| 奖励反馈 | 暴击/击杀/登场演出 + 奖励粒子 | GAME-FEEL.md |
| 目标 | 首页动态目标卡（既有）+ 图鉴收集进度（新） | HOME-REDESIGN.md |

## 二、战斗页面结构（battleHtml）

```
顶栏：章节/关卡/波次进度
中部：[玩家列] [敌人列(意图+打断窗口+P2标签)] [战利品列]
底部：回合/能量/连击徽章 + 手牌 + 结束回合
移动端（≤899px）：单列堆叠，手牌区完整可见于底部导航之上
```

- 敌人意图（攻击/防御/削弱/召唤/特殊机制）保持权威引擎状态驱动。
- 手牌费率异常（需求费率上调）直接反映在卡牌费用角标。
- 切页返回不重建战斗（既有 battle-signature 缓存保持，V7.0）。

## 三、养成页面

- 员工：招募/升级/羁绊（既有 V6.4）。
- 装备：槽位/背包/强化（既有 V64）。
- 卡组：挑战页卡组区新增流派倾向 + 净化 + 图鉴（本轮）。

## 四、玩家短期/中期/长期目标（首页动态目标卡既有实现 + 本轮增强）

| 层级 | 内容 | 现状 |
|---|---|---|
| 短期 | 今日目标 3 条（工作任务/真实成长/生活社交）+ 领取 | 已有，首屏可见 |
| 中期 | 当前章节推关目标（Boss pending → 挑战 CTA） | 已有 |
| 长期 | 章节进度条（第 N 章 x%）+ 卡牌图鉴收集进度（新） | 本轮补图鉴 |

不用红点轰炸：首页保持单一主 CTA（进入战斗）。

## 五、弹窗治理（§十三）

| 规则 | 实现 |
|---|---|
| 战斗中无关弹窗不遮挡 | **V10.1 新增**：升级三选一期间不弹可选职场事件（ui-overlay-v2.js maybeShowV2EventModal 让位） |
| 普通消息用 Toast | 既有（toast 管线） |
| 关键选择用 Modal | 事件选项/技能三选一/卡牌奖励均为带选项 Modal |
| 弹窗必须可关/明确下一步 | 全部事件弹窗带「知道了」或选项按钮 |
| 不出现多个弹窗争夺焦点 | 单 popupLayer 仲裁（V7.0 机制保持 + 本轮优先级修正） |
