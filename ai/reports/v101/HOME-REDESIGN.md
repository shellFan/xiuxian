# V10.1 首页与五页面 UI 重构（HOME-REDESIGN / UI-UX-REDESIGN）

## 一、首页（洞府）——问题与修复

### 问题（before 截图证据：`screenshots/before/02-home-fresh.png`）
1. **主角展示区渲染为纵向大卡**：V9.1 设计为横向紧凑卡（120px 立绘 + 信息右侧），但遗留
   `.ux-hero { flex-direction: column }` 泄漏进 `.ux91-hero`（同权重选择器、后者未声明方向），
   导致立绘居中 + 信息堆叠，首屏被挤满。
2. **1280×720 第一屏看不到「今日修行」**：主角区 ~330px 高，把最高频的日常操作（工作/摸鱼/
   修炼/社交）挤出首屏，玩家要滚动才能干活。
3. 立绘溢出容器（SpriteAnimPlayer scale 1.15 无裁切）。

### 修复（CSS + 结构微调，不动五区信息架构）
1. `.ux91-hero { flex-direction: row }` 显式声明 + `.ux91-hero-art { overflow: hidden }` 裁切。
2. `renderCave` 将 hero/today/quick 包进 `.ux91-mid`：
   - 桌面 ≥900px：`grid: 5fr | 7fr`，**主角 | 今日修行并排**，第一屏 = 资源 + 当前目标 + 主角 + 今日修行；
   - 移动端 <900px：维持纵向堆叠（移动端屏窄，纵列正确）。
3. 快捷入口（员工/装备/晋升）横跨双栏于第三行。

### 首屏内容优先级（实现后）
```
顶栏（品牌/日期/NPC一句话/全局入口）
资源栏（灵石/修为/道心）
当前目标大卡（动态状态机 CTA + 章节进度）
[主角(紧凑) | 今日修行(4 模式卡)]   ← 并排
快捷入口（员工/装备/晋升）
次级内容（V59F 面板/工作台/生活/合成/右栏）
```
