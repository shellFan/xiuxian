# V10.1 性能对照（PERFORMANCE）

对照基线：HEAD 085013a（V10.0 RC）。所有数字来自真实运行（Electron 无 preload H5 上下文 / 打包 EXE）。

## 一、启动

| 指标 | V10.0 基线 | V10.1 | 说明 |
|---|---|---|---|
| 冷启动 facade 就绪 | ~19s（61 资源） | ~19s（61 资源，final-desktop 实测 19s 档） | 无回归（卡池 52→67 不影响启动路径，配置同包） |
| 打包 EXE facade 就绪 | — | 3~19s（exe-smoke 实测） | asar 内本地加载 |

## 二、运行时

| 指标 | V10.0 | V10.1 | 变化 |
|---|---|---|---|
| 主刷新循环 | 1s 间隔 + battle-signature 增量刷新 | 不变 | 无新增定时器 |
| 常驻事件监听 | onUiEvent 5 类 + 既有 | 不变 | 新增特效均为一次性 DOM 节点（Boss 横幅 2.2s 自动移除；粒子 ≤1.1s） |
| 战斗 UI DOM | 手牌 10 + 敌人列 | 同（新增打断窗口为意图行内元素） | 无结构性增长 |
| 卡组页 | 只渲染已拥有行 | 新增图鉴区（51 卡）+ 流派条 | 仅卡组页按需渲染，非战斗热路径 |

## 三、特效开销约束

- 单次动作特效：粒子 8~16 颗 / 寿命 ≤1.1s / CSS 动画（GPU 合成层）。
- `prefers-reduced-motion` 全局降级保持。
- 屏幕震动为 CSS transform 动画（既有实现），未增加 JS 每帧计算。

## 四、不做"关动画式优化"

本轮所有性能相关设计均为结构约束（节点自动移除、按需渲染、增量刷新保持），
未通过减少反馈/动画来制造性能数字。

## 五、验证方式

- 全量回归 174 文件 EXIT=0（含 perf-guard/leak-protection 既有守护测试）。
- EXE 30min soak：引用 V9.2/V10.0 通过记录（heap 24.7–34.3MB 稳定）；本轮变更
  未触及 game-loop/tick 管线，风险面在战斗结算（同步、无新增循环计时器）。
