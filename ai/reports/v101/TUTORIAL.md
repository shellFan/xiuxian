# V10.1 新手引导与成长体系（TUTORIAL / PROGRESSION）

## 一、新手引导现状审查（真实跑通验证）

本轮审计全流程实测创建→开局路径（每轮 40s 内完成 17 步向导 + 引导剧情）：

| 环节 | 现状 | 评估 |
|---|---|---|
| 选职业 | V5.9 七步向导（行业→方向→职业→身份→背景→天命→加点→确认） | 保留，契约测试覆盖 |
| 认识宗门/资源 | 入职剧情 onboarding（可跳过，跳过后仍可完整游玩） | 保留 |
| 首次战斗教学 | 卡牌战斗首战引导 6 步（生命/敌人意图/能量/出牌/回合/奖励），`v59o_battle_tutorial_done` 持久化，跳过后不重弹 | 保留 |
| 第一次工作/修炼 | 首页今日修行区 + 新手目标 3 条（工作任务/真实成长/生活社交，领取制） | 保留 |
| 重进不重弹 | 向导状态 `characterSetupStatus` + 引导 flag 持久化 | 验证：重启后直接进洞府 |

### 本轮引导相关修复
1. **"尚未开工"死胡同消除**：战斗入口自动开工（此前新玩家直接挑战会收到无引导的报错）。
2. **战斗内升级三选一优先于可选事件弹窗**：新手首战升级时不再被职场事件弹窗卡住出牌
   （此为真实弹窗争焦点的修复，见 MOBILE-UI.md）。
3. 引导步骤文案保持"每步只讲当前必要内容"原则，未增加连续弹窗。

## 二、成长目标体系

| 层级 | 载体 | 状态 |

### 卡牌图鉴（新）
- 挑战页卡组区新增图鉴：全部 51 张可获卡（rewardable）收集状态 + 进度 n/m。
- 收集维度与卡池扩容（67 卡）配套：流派卡=构筑目标，图鉴=长期收集目标。

## 三、弹窗分类治理（§十三）

| 类别 | 处理 |
|---|---|
| 强制操作弹窗 | 创建向导/onboarding（流程必需） |
| 重要结果弹窗 | 战斗结算/奖励三选一/晋升答辩 |
| 可选奖励弹窗 | 职场事件（本轮：战斗中让位于技能选择） |
| 普通通知 | Toast（既有） |
| NPC 消息 | 飞剑传书 Widget（入口在顶栏，不占首页主区） |

连续事件合并/Toast 化由既有 V6.8/V7.0 仲裁机制承担（单 popupLayer + 优先级）。
