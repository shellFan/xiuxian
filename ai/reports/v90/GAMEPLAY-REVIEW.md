# V9.0 玩法审查报告

## 1. 核心循环

战斗（独立页）→ 资源/击杀 → 洞府查看成长 → 养成页培养员工/装备 → 战力提升 → 战斗页推进 → 第 12/25/… 关卡牌 Boss → 挑战页策略 → 晋升 → 通天塔。

五页架构使循环的每个环节有明确页面承载：
- 战斗页 = 执行战斗（舞台视觉中心，无干扰）
- 洞府 = 查看状态 + 选择下一步（挑战卡 + 入口宫格）
- 养成页 = 花资源变强（招募/装备/羁绊内联可见）
- 挑战页 = 高难内容（卡牌 Build / 通天塔 / 项目档案）

实测：路由探针穿越五页后战斗状态持续（stage 1→2→3 后台推进）。

## 2. 自动战斗与点击

- 自动战斗节奏：16× 缩放下前期快速推关（EXE soak 时间线：0s→第1关、31s→第5关、93s→第11关——快节奏符合放置类正反馈设计）
- 点击价值：tapAttack touchend 即时响应（移动端）+ click（桌面）；伤害/飘字/受击特效实测
- Boss 切换：miniBoss 每 5 关，cardBoss 每 ~13 关（强制卡牌减速点）

## 3. 四技能策略

| 技能 | 定位 | 使用价值场景 |
|---|---|---|
| 代码飞剑 | 单体高伤 | 精英/Boss 血量压制 |
| Bug 炸弹 | 群体/AOE | 多小怪波次 |
| 需求粉碎 | 破盾 | 护盾型 Boss（SHIELD 特性反制） |
| 紧急回滚 | 防御/恢复 | 爆发型 Boss（BURST 特性反制） |

差异化的 Boss 特性（SHIELD/BURST/CONTROL/DOT）使不同技能在不同战斗中有价值；defeatAdvice 按特性给反制建议。
