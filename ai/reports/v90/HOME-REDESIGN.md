# V9.1 洞府首页重构报告（HOME-REDESIGN.md）

## 1. 设计目标达成

将洞府首页从 V9.0 的功能集合页改造为**真正的游戏成长中心**。

### Before（V9.0 洞府）

- 资源 4 卡 + 战斗舞台(在洞府内) + 角色卡(含宗门/证据袋/功法链接) + 工作场景 + 行动详情 + 状态条 + 今日目标面板 + 晋升目标 + 旅程引导 + 右栏(日程/飞书/动态/生活) + 合成盘 — **11 个区块堆叠，信息过载**

### After（V9.1 洞府）

- **仅 5 区**：资源栏(3 chips) → 主角展示(Sprite 立绘+境界+战力+修为进度+修炼按钮) → 动态目标(状态机+CTA) → 今日修行(模式卡+道心+收益) → 快捷入口(员工/装备/晋升)
- 合成盘、工作场景、行动详情、右栏日程、旅程引导保留但移至页面下方（非首屏焦点）

## 2. 组件调整

| 区域 | Before | After | 变更 |
|---|---|---|---|
| A 资源栏 | 4 大卡片（修为/工资/道心/绩效） | **3 chips**（灵石/修为/道心） | 工资/绩效移入 D 区收益摘要 |
| B 主角展示 | 小头像+文字（无立绘） | **Sprite 动画立绘**（mountCaveHero 1.15×）+ 职级/境界/战力/修为进度/修炼按钮 | 角色成为视觉主体 |
| C 当前目标 | 静态挑战卡（固定文本） | **动态状态机**：Boss 待战→挑战 Boss / 晋升满足→完成晋升 / 新手→首次推关 / 默认→继续修炼 | 同一时间一个目标，CTA 随状态变 |
| D 今日修行 | 大模式卡+详细面板 | 紧凑模式卡 + 道心 + 收益摘要 | 保留全部模式切换/生活行动功能 |
| E 快捷入口 | 6 宫格（战斗/养成/挑战/晋升/任务/飞剑） | **3 按钮**（员工/装备/晋升） | 挑战/任务/飞剑通过底部导航 |
| 合成盘 | 洞府页内 | 洞府页下方（非首屏焦点） | 保留功能不删除 |
| 工作场景/详情 | 洞府页中间 | 洞府页下方 | 保留（契约需要加班/倒计时 UI） |

## 3. 动态目标状态机

| 状态 | 条件 | CTA | 去向 |
|---|---|---|---|
| Boss 待战 | status === BOSS_PENDING | 挑战 Boss | BATTLE 页 |
| 晋升满足 | queryPromotionCheck().allowed | 完成晋升 | PROMOTION 页 |
| 新手试炼 | stage ≤ 3 && kills < 10 | 进入战斗 | BATTLE 页 |
| 默认 | — | 继续战斗 | BATTLE 页 |

CTA 按钮颜色随状态变化：Boss = 红色，其余 = 金色。次要目标行显示未领取的今日目标。

## 4. 主角 Sprite 动画

- `mountCaveHero(el, professionId)` — 1.15× 大尺寸职业 Sprite
- `mountSprites()` 检测 `#Ux90CaveHero` 元素自动挂载
- 使用 `ux91-hero-sprite` class（无圆形裁剪，原始比例）

## 6. 缺陷及修复

| 缺陷 | 修复 |
|---|---|
| 洞府 Sprite 被圆形裁剪（ux66-squad-sprite class） | 改用 ux91-hero-sprite class（无裁剪） |
| 契约测试期望旧首页元素 | 契约随 V9.1 设计更新（nav 五页 / 家宽 922 / 洞府入口） |
