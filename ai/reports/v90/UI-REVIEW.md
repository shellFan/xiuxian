# V9.0 UI 审查报告

截图对照：`screenshots/before/`（V8.0 单页布局）vs `screenshots/after/`（V9.0 五页架构）vs `screenshots/mobile/`（H5 移动视口）。

## 1. 首页（洞府）——真正的重新设计

| 项 | V8.0（Before） | V9.0（After） |
|---|---|---|
| 定位 | 战斗舞台占主体 + 养成/目标堆叠 | **角色成长中心**：挑战卡 + 角色 + 目标 + 入口宫格 |
| 进入战斗 | 无独立入口（战斗在页面内） | **金色「⚔️ 进入战斗」大按钮**（挑战卡内） |
| 当前挑战 | 混在战斗区 | 洞府挑战卡：章节/关卡/敌人/血量/击杀/战力/状态标签 |
| 页面构成 | 战斗区+合成盘+工作场景+目标+右栏全部堆叠 | 资源条→挑战卡→角色→工作场景→入口宫格→状态→目标→右栏→合成盘（分层清晰） |

## 2. 独立战斗页（新）

- 全屏战斗舞台（920px 主列 + min-height 456），无养成/目标干扰
- 关卡头（章节/关卡/战力/推荐/Boss 待战标签）+ 敌人 Sprite + 血条 + 小队 + 四技能 + 操作条 + DPS
- 战斗舞台签名保留：跨页返回不重挂载、动画不归零、状态持续实测（stage 1→2→3 后台推进）

## 3. 养成页（新）

- 战力概览 + 项目小队 + **内联招募面板**（价格/余额可见，无遮罩弹窗）
- **内联装备面板**（槽位/背包/穿戴/强化，按钮直接可点）
- 职业羁绊一览（激活态高亮 + 定义说明）
- 合成盘保留在洞府页

## 4. 移动端（≤560px 断点）

- 主列/舞台 100% 宽
- 底部导航 `calc(64px + safe-area-inset-bottom)`
- 技能按钮 62px 高、招募项 48px、装备小按钮 44×32
- 实测 4 宽度 0 横向溢出、nav 视口内

## 5. 组件统一

- 图标集（墨玉描金 10 枚）保持
- 按钮体系：`.ux-cave-cta`（主 CTA）/ `.ux-cave-entry`（宫格）/ `.ux65-btn`（战斗操作）统一风格
- 卡片：`.ux-cave-battle-card` / `.ux-grow-card` 统一暗玉底 + 金描边
