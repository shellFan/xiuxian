# Q版牛马角色视觉指南

## 共用造型

2.5头身、牛耳宽、短钝牛角、圆鼻口、人形身体、三指手套；不是写实动物，也不是马脸人。眼睛能读出“想下班”，不使用病态黑眼圈制造羞辱。暖灰棕皮肤、奶油口鼻、墨色线条（750设计基准描边3–5），肩窄腿短，手持职场物品；不靠性别/体型刻板印象表示能力。

45°轻俯视工位姿态与3/4正面卡面共享头部比例。主光左上，阴影右下软边。正向成长是装备、工牌、坐姿、轮廓与光环层级变化，不只是换颜色。每级至少改变两个轮廓特征；小尺寸64px仍能辨角与法器。

## 生产拆层

body、face、accessory、held_prop、aura、shadow 分层；尺寸统一512×512角色画布、脚底锚点(0.5,0.12)，导出透明PNG，512不是手机显示尺寸。首版站立/工作/摸鱼/开心/受挫各2–4帧，不上复杂骨骼。动作不带业务文字，工牌文字在UI绘制。

验收：10张缩到64px仍有等级差；剪影可区分；双角不被裁；脚底锚一致；透明边无白边；手不多指；道具不穿模；没有品牌logo；肤色比例与主光一致。生成图只是候选，需美术人工筛选与Cocos导入验证。
