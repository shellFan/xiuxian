# Content Release Checklist

适用候选→正式运行时接入前；每条由内容owner记录版本、证据、审核人。未打勾表示发布待验，不是忘记补PASS。

- [ ] 全量80事件/31成就/12每日/6教程逐字复读：错别字、全半角、术语、重复标题与近似笑点。
- [ ] Schema与语义检查全绿，effect/reward只用四资源，source条件/奖励变更有单独审批。
- [ ] zh-CN重复key（包含转义等价键）和missing key为0，所有按钮/错误/choice文本可解析；占位变量有显式参数表，未知变量阻断。
- [ ] 工资=余额、修为=cultivation→cultivationExp、道心受max约束；缩写不用于计算。reward文案与实际clamp后量一致。
- [ ] EVENT_AFTERNOON_TEA“回满”矛盾修订获批准；35岁/3.25与性别称谓的源文案审核完成；团建支配选项裁决完成。
- [ ] 不诋毁真实公司或人物，无歧视/地域/政治攻击、违法建议、严重辱骂/低俗；品牌名不暗示授权/背书。
- [ ] 6隐藏成就LOCKED的标题/条件/奖励/进度/稀有度/tooltip/无障碍树均不泄漏，池复用不会残留上一项。
- [ ] 750×1334到20:9、small/notch/hole/home indicator、字体1.0与1.3：无截断金额/关键操作，长内容可滚动。
- [ ] 所有广告按钮明示“看广告”，默认正常玩法无广告；取消/失败不锁UI，不把晋升重试写成必定成功。
- [ ] 每日显示真实刷新时间（UTC日=北京08:00），不把随机5–6候选文案用于旧全量服务。
- [ ] 事件effects与文案逐项匹配；选择不漏代价，负数显示减号；不把类别NEGATIVE误当“只能负delta”。
- [ ] 美术/音频来自有使用权的来源，mustReview人工通过，隐藏内容不配剧透缩略图；不以PLANNED文件占位冒充真实资源。
- [ ] 资产预算以导入后真机测量校验；不把设计MiB目标写成微信官方限制。
- [ ] 兼容表MAINLINE_CHANGE_REQUIRED全部由对应owner关闭，生成新SHA预览；未支持FISH_SECONDS/随机daily不激活。
- [ ] Editor脚本UUID、Inspector绑定、运行与真机触摸/生命周期/广告由主线实测并签字。

本轮完成的是候选包与检查工具；发布清单保持待验。主线范围外的问题不可用Mock、TypeScript通过或假截图替代验收。
