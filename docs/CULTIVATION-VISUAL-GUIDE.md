# 境界视觉体系

本轮设计炼气/筑基/金丹/元婴四组，保留源配置“练气境”等原文；资源名统一 `lianqi`，不擅自修改存档或career配置。

| 境界 | 边框 | 光效 / Aura | 称号样式 | 晋升动画 | UI icon |
|---|---|---|---|---|---|
| 炼气（源：练气境） | 单线玉青、两个短角 | 一条低透明气流，非持续粒子 | 墨色字+青色短底线 | 纸符翻开，气线沿角一圈，600ms | 线圈包住小牛角 |
| 筑基 | 双线青玉、方形基座 | 四角定点辉光，脚底方阵 | 角形左标+青玉底签 | 四块工位印章合成方阵，720ms | 方阵+键帽 |
| 金丹 | 旧金内框、圆角八边 | 胸前金点、断续圆环 | 金色描边牌，文字仍深墨 | 圆形绩效章凝成金丹，820ms | 金色丹丸+工资条纹 |
| 元婴 | 紫墨外框、银白内线 | 小型牛马分身剪影、双层断环 | 紫底浅字+双角冠标 | 分身从工牌跃出，鞠躬回环，900ms | 牛角灵体+双环 |

颜色之外必须有边框形状、图标与环数量变化，色弱用户也能辨级。持续光效不能盖住资源数字或拖动目标；每个角色最多1个轻量tween，无满屏常驻粒子。

源career 5–10还有化神/炼虚/合体/大乘/渡劫/飞升：本轮不虚构为元婴。展示真实文字，使用“高级境界中性框”静态fallback并标记美术待补；不得把相同图标宣称为已完成的后六境界体系。相关资源扩展是后续接入工作。

晋升成功以服务返回为前提；失败只播放卷轴合上+淡烟300ms，不扣第二次资源、不改变称号。跳过动画立刻显示最终权威状态；减少动态只换徽章并淡入100ms。声音依据音效计划，静音无影响。

资源：`ui/cultivation/realm_lianqi_badge` 等4徽章；`ui/effects/realm_*_promotion`，sprite裁切不携带文字。小徽章128×128、展示48/56；大徽章256×256用于弹窗。导入验收四级并排、64px缩略、背景明暗两版与白边检查。
