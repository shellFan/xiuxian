# First 10 Minutes — 首个十分钟体验脚本

> 对应 V4.1 软引导（tutorialVersion = 2，步骤 WELCOME → FIRST_WORK → FIRST_FISH →
> FIRST_CULTIVATE → FIRST_TASK）。引导为只读提示，不拦截输入、无命令前置条件，
> 每条提示在触发动作后或 30 游戏秒后消失。PC 首页 1280×720 单屏可见全部入口。

## 0:00 – 0:30 启动与欢迎

- 启动后进入 PC 首页（方案 B 布局）：顶栏品牌与状态、左侧角色卡、中央下班倒计时场景、四张动作卡、右栏今日待办、底部六项导航（首页 / 任务 / 项目 / 修仙 / 晋升 / 更多）。
- 新档自动进入 WELCOME 引导：「欢迎入职牛马修仙传！白天上班，晚上渡劫——先活过今天。」场景顶部有金色引导条（data-tutorial-hint），不遮罩、不锁输入，30 秒后自动消失。
- 若存在离线简报（欢迎回来弹窗），点击「继续上班」领取后进入首日。

## 1:00 – 3:00 三个核心动作

| 动作 | 入口 | 真实反馈 |
|---|---|---|
| 努力工作 | 动作卡「努力工作」→ 详情「开始工作」 | 工资与修为按 1.3× / 0.8× 挂机倍率入账；详情面板显示当前塞来的活（P0/P1/P2） |
| 带薪摸鱼 | 动作卡「带薪摸鱼」→「开始摸鱼」 | 道心 +36/小时，工资按 0.6× 结算；详情面板实时显示「本次摸鱼已入账」 |
| 修炼一次 | 动作卡「修炼一次」→「开始修炼」 | 立即结算修为 +2~6、道心 +1（facade.cultivate()），详情面板有 +N 浮字反馈；冷却期间按钮说明原因 |
| 进入修炼状态 | 修炼详情「进入修炼状态」 | 挂机修为 ×2.0、工资 ×0.3 的长期状态，可随时切回 |

引导条随真实动作自动推进：工作后出现 FIRST_FISH，摸鱼后出现 FIRST_CULTIVATE，以此类推。玩家不按引导操作也不会锁死——提示只会在 30 秒后过期。

## 3:00 – 10:00 第一个任务与项目

- 底部导航「任务」打开任务页（日常 / 工作 / 修炼三个分类）。首日可见「写日报」（10 秒，工资 +10、修为 +30、绩效 +5）等真实任务，点「开始」出现倒计时，完成后「领取」。
- 首个职场事件在开工后数分钟自然出现（确定性首日为带两个选择的正常事件），弹窗内选择 A/B/B均有真实收益与代价；事件也会计入右栏「最近动态」。
- 底部导航「项目」进入项目页：「选择 Build 进入项目」（Java并发流 / 数据库事务宗 / 缓存击穿掌 / 摸鱼养生流）进入五波自动战斗（普通 → 精英 → Boss）。战斗中升级触发技能三选一；Boss 胜利自动完成当前待办并掉落材料/法宝。这是正常玩家路径，不依赖 DEV 面板。
- 17:55 前后首页场景进入暖色黄昏氛围，出现加班询问（可明确拒绝）。
