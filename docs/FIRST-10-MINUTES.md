# First 10 Minutes — 可执行体验脚本

候选UX目标，不是模拟实测。计时按前台可交互时间，加载/背景/平台广告不算。源代码招募当前免费且只受空位限制；首次职业KPI=合成3次、累计WORK300秒、修为50。不能因为按钮显示“准备答辩”就保证5分钟晋升成功。教程FIRST_PROMOTION会等真实career>=2，等待时不可全屏锁输入。

| 时间 | 玩家看到 / 做什么 | 反馈与退出条件 |
|---|---|---|
| 00:00–00:20 | 启动恢复真实状态；新档空盘与招募高亮 | 加载失败留重试页、不盖旧档；老档跳过已完成引导 |
| 00:20–00:50 | FIRST_RECRUIT，点招募；SECOND_RECRUIT再点一次 | 两个Lv1真实出现；不显示不存在的招募成本 |
| 00:50–01:30 | FIRST_MERGE，拖一只到另一只 | 第一次爽点：target留Lv2，source空；首档合成奖励工资10、修为5（economy.json），只有成功才飞字 |
| 01:30–02:00 | START_WORK，理解工作/摸鱼切换 | 服务首个正收入刷新工资；不得为“首工资”额外赠未配置奖励 |
| 02:00–03:00 | CHECK_KPI，打开条件；再招募合成 | 看3项真实进度；解释工作累计300秒，不伪装2分钟全部达标；有可合对给非强制提示 |
| 03:00–05:00 | 首事件机会：原服务3–8分；拟议3–5分 | 事件未到展示合成/任务方向，不补造事件；choice清楚收益代价，处理一次 |
| 05:00–07:00 | KPI接近达标，继续合成/工作或主动摸鱼恢复 | 从02:00持续工作则最早约07:00达到300秒；修为/合成也须达到；未到显示缺项 |
| 07:00–09:00 | 晋升预告，了解当前概率，达标者可首次尝试 | 成功由服务决定；失败保持工牌与真实损失，不假保底。已有主线重试广告约束须后续修复 |
| 09:00–10:00 | 查看已达成成就/每日任务，或继续合成 | 给实际可领项，不为脚本伪造完成；10分前不主动展示广告机会 |

第一次广告机会目标在10–15分且核心循环已理解、强引导不遮罩时，由玩家自愿打开奖励入口；没合格奖励/Provider未准备好则不出现。第一次promotion只是预告/尝试，不承诺成功或具体职级。6步教程文字在tutorial-copy.json；CHECK_KPI可由明确打开动作advance，自动条件仍为KPI完成，以主线服务为准。

验收观察：1–3分钟能复述“招募同级合成、工作涨资源、摸鱼养道心、KPI指方向”；5–10分钟至少真实合成升级与工资变化可见。若资源恢复/事件等待造成空档，提供已可用行动，不临时改数值。需要Editor/真机体验记录，未声称该脚本已跑通。
