# First 30 Minutes — 首个三十分钟体验脚本

> 延续 `FIRST-10-MINUTES.md`。所有描述均对应当前真实实现（V4/V4.1）；
> 旧 Merge（招募牛马 / 同级合成）不再是首玩路径，仅作为「更多」页中的兼容系统保留。

## 0 – 10 分钟：核心循环跑通

- 工作 / 摸鱼 / 修炼 / 任务四个动作全部可自由切换（PC 首页动作卡 + 详情面板；切换即时生效）。
- 四项资源在左侧角色卡紧凑列表中实时更新：修为（含 / 所需）、工资（含每分钟速率）、绩效、道心（含上限）。
- 首个任务「写日报」10 秒即可完成领取；任务页三个分类各有真实奖励的任务池。
- 首个职场事件为双选择事件（seed 4101 首日确定性事件），选择有真实代价与收益。

## 10 – 20 分钟：项目 / Combat / 技能与掉落

- 「项目」页选择 Build 进入五波战斗：普通怪 → 精英 → Boss。
- 击杀获得修为经验；升级暂停战斗弹出**技能三选一**（如线程分身、慢 SQL 光环等）。
- 掉落物进入材料与法宝体系（Boss 战利品弹窗一次结算，奖励 exactly-once 持久化，重启不重复）。
- Boss 胜利会自动完成当前一条待办——战斗与任务系统互相咬合。
- 生产事故（S1/S2）相关内容在前五分钟受新手保护屏蔽（见 FIRST-DAY-EXPERIENCE.md），之后随事件自然出现。

## 15 – 30 分钟：职场系统渐进

| 系统 | 首日呈现方式 |
|---|---|
| NPC / 人际 | 茶水间社交（动作卡「社交划水」）展示 NPC 推荐与关系阶段；关系随事件选择变化 |
| 证据 | 事件与事故留痕进入「证据袋」（角色卡入口）；用于事件选项解锁与复盘定责 |
| 责任 / 背锅 | 背锅与反击通过事件与事故结算呈现，首日至少可观察到一次选择带来的责任后果 |
| 技术债 | 以「今日局势」chip（如沉迷战略）与项目节奏间接呈现；60 天矩阵验证 RUSH/QUALITY/BALANCED 均 viable |
| 事件链 | 老板画饼、祖传屎山、厕所秘境等链式事件按日程自然触发 |

## 17:55 – 18:00：下班氛围与选择

- 17:55 起首页场景切入黄昏氛围，倒计时只剩 5 分钟；老板可能发出「免费加班 2 小时」询问。
- **接受**或**婉拒**都是明确的一等选择：婉拒后 18:00 前同一请求不会重复出现，且不记任何加班工资。
- 18:00：若未加班，首页出现「查看今日结算」；结算弹窗给出称号、评级、四类时长与当日收入。

## 18:00 之后

- 日结算：工资 / 修为 / 绩效入账、当日四活动时长（工作 / 摸鱼 / 修炼 / 社交）、事件数、材料数、带薪摸鱼收入、背锅与事故统计。
- 结算后进入次日循环；离线（关闭游戏）期间的收益遵循 AutoPolicy（均衡 / 稳健 / 卷王 / 摸鱼），下次启动以「欢迎回来」简报呈现，高风险破事保留为待你决策。

## 首日不出现的系统（避免误导预期）

- 晋升渡劫答辩（需职级条件）、周末安排、管理层 / 周结算、复杂 S1 事故链、广告位强推。
- 这些系统的入口与条件真实存在，但不属于第一天：文档与 UI 不做虚假承诺。
