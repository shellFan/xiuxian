# First 30 Minutes

延续FIRST-10-MINUTES，所有时间为体验目标、非奖励/晋升承诺。每段提供至少一个不依赖广告的可操作路径；不新增运行时功能。

| 区间 | 主线行为 | 次目标/回馈 | 不可达时fallback |
|---|---|---|---|
| 00–03分 | 两次招募、首次合成、开始工作 | Lv2、第一条工资增量；理解四资源 | 配置/存档失败返回可恢复启动；不教看广告 |
| 03–10分 | 查看KPI、再合成、首事件待出现 | 可领的首合成成就；工作300秒与修为50目标 | 事件未出现继续盘面操作；满盘提示合对，不强弹广告 |
| 10–15分 | 达标后首次晋升尝试/预告；任务页找可完成项 | 首次可选广告机会只在非强引导、实际价值明确的奖励位 | 未达标列缺项；失败可回普通玩法，非广告晋升重试能力属主线待补 |
| 15–20分 | 工作/摸鱼交替，继续合并提升盘面 | 道心恢复、每日WORK/FISH实际进度、少量事件 | 不为了任务同时要求两模式；不要凭终身计数判当日达成 |
| 20–25分 | 领取真实达成项，检查下一KPI门槛 | 职业/境界预览、办公室视觉期待 | 不保证office升级或看到稀有彩蛋；不要用广告填内容间隔 |
| 25–30分 | 自选合成/目标，形成短回访预期 | 说明离线有上限、下次回来普通领取 | 可主动退出，不设留人倒计时；实际离线结算由服务 |

节奏规则：连续45秒无输入且非弹窗/拖拽时，仅一次轻提示“同级可以合成/看看KPI”；本轮是设计，不能假称已有提示服务。连续3分钟无可操作路径记录体验失败并交主线调参，不靠文案掩盖。道心低先教摸鱼，不先卖恢复广告；广告间隔/上限见IAA-FREQUENCY-V1。

验收记录：首次合成时间、工作理解时间、首事件时间、KPI达标时间、晋升尝试与结果、无广告路径是否阻塞、满盘恢复、每段最长空等。当前PromotionService失败后需要RewardProvider重试，是已知“不看广告长期成长”缺口；不能以本脚本证明已解决。所有测量待Cocos Editor与微信真机执行。
