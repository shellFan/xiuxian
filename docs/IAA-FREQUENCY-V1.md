# IAA Frequency V1（产品建议，尚未写入服务）

继承IAA-DESIGN七奖励位；优先执行更严格限制。V1仅自愿激励，不插屏、不自动播放、不以广告作为教学目标。上限不是营收目标，不鼓励“刷满”。

全局：成功观看最多8次/UTC日、3次/session；session从冷启动至终止，短暂后台不新建；全局两次广告开始至少180秒。首次广告机会延迟到活跃10分钟且首次合成已完成、强引导关闭，奖励入口此前不高亮。普通领取始终优先。离线重访也遵守session延迟，可先正常领取，不能为等广告阻止入账。

两次连续cancelled（不同request）后，主动推荐隐藏30分钟，保留玩家自己打开的入口；三次连续cancelled后本session不再主动推荐。failed/no-fill不是用户取消：5分钟不再推荐且不自动重试。计数在未来服务持久化，重开不规避日限；任一granted清取消连击，不能清日总数。取消也消耗开始间隔（若未进入播放器只受5秒按钮防抖）；成功限额只算业务最终granted，未知事务预留名额防止超发。

需要能力：可信dayKey、幂等请求账本、activeTime、placement预览、明确服务可用性。当前主线没有完整全局限频，不能通过按钮灰化声称已执行。晋升失败依赖广告、免费普通招募使“广告免费招募”价值不明确，均待主线产品裁决；这些位在冲突解决前不推荐启用。

验收目标：全程拒绝广告仍可操作合成/工作/摸鱼/任务；完整长期晋升无广告路径须补齐后再PASS。不用“看完必升职”“错过就亏”等误导文案。正式接SDK时由主线另验平台政策，本文件不声称合规认证。
