# 数值展示规范

统一使用国际短单位K/M/B/T，不混入万/亿；中文标签仍用工资、修为等。精确弹层采用三位逗号分组。格式化仅用于展示，永不把格式化字符串解析回经济运算。

## 规则

| 类型 | 主展示 | 精确/说明 |
|---|---|---|
| 工资/修为 | <1000展示整数；>=1000按1000进阶，1位小数、去尾零 | 点开完整整数；工资单位“灵石”，修为单位“点” |
| 绩效/道心 | 整数；道心展示current/max | 不用K隐藏0–100道心；最大值来自Service |
| KPI | 当前 / 目标，完成项数 / 总项数 | 大数可短显，但明细完整；不同计量不能相加 |
| 百分比 | 0–100%，最多1位小数 | 概率来自服务ratio×100；不把0.035显示35% |
| 倍率 | ×1.2；加成为+20% | 必须区分总倍率1.2与额外比例0.2 |
| 倒计时 | <1小时mm:ss；>=1小时HH:mm:ss | 用ceil(remainingMs/1000)，最小0；后台恢复按deadline算 |
| 累计时长 | 2小时3分；<1分显示N秒 | floor总秒，非墙钟、不做时区转换 |
| 资源变化 | +20 / −8；0不飞字 | 由实际结果delta而非配置预估；红绿以外带符号 |
| 未知/非法 | — | NaN/Infinity/越界禁止当0；记录DEV诊断 |

资源短格式对绝对值**向下截断**一位，再恢复符号，以免显示够钱但实际不足；阈值选择按原始绝对值，不四舍五入跨单位。负数只用于delta/诊断，合法钱包由Service约束。精确整数超过Number.MAX_SAFE_INTEGER时显示“数值异常”，不能继续补零伪造精度。最大短单位T，超出999T时仍使用T且不自动改科学计数；明细优先，合法上限仍由服务定。

## 验收样例

| 输入 | 输出 |
|---:|---|
| 0 | 0 |
| 999 | 999 |
| 1000 | 1K |
| 1250 | 1.2K |
| 12500 | 12.5K |
| 999999 | 999.9K |
| 1000000 | 1M |
| 1200000 | 1.2M |
| 1500000000 | 1.5B |
| −1250（delta） | −1.2K |
| ratio 0.035 | 3.5% |
| remaining 1ms | 00:01 |
| remaining 0ms | 00:00 |
| duration 3661s | 1小时1分（详情1小时1分1秒） |
| NaN / Infinity | — |

精确价格tooltip与主按钮禁用逻辑必须取同一权威值；例如999.9K显示不意味着1000000招募价可买。资源Label使用等宽数字或固定容器，字体不为长数无限缩小。实现formatter时用纯函数、注入locale策略并覆盖上述边界；本轮仅规格，未新增TypeScript formatter。
