# UI 信息架构

状态：Phase 4 接入设计，不代表页面已在 Cocos 完成。口号：**上班修的是仙，掉的是头发。**

## 导航规则

启动 → 主游戏；底栏「牛马 / 职业 / 宗门 / 事件」。右侧「任务 / 成就 / 设置」。KPI 是 HUD 进度入口，不占底栏。主游戏保持同一 Session，切页只换 View。弹窗遵循 [设计系统](UI-DESIGN-SYSTEM.md)，同一时刻一个交易型 Modal，返回按弹窗→子页→主游戏消费，不退出小游戏。

全局状态含 LOADING / READY / EMPTY / ERROR / BUSY / DISABLED；权限或机制未接入时显示「后续开放」，不能露出可点但无响应的按钮。未知资源显示“—”，不能伪造 0。屏幕阅读顺序为标题→资源→内容→主操作→次操作。

## 01 启动页

- 目的：恢复存档、配置与单一 Session；牛马抱笔记本御剑穿过写字楼。
- 入口：冷启动、主动重新进入；退出：初始化成功进入主游戏，失败留本页。
- 核心信息：游戏名、口号、真实加载阶段，不显示假百分比。
- 主要按钮：失败后「重新连接」；次要按钮：「问题说明」，不提供直接清档。
- 状态：加载 / 恢复 / 完成 / 失败；空状态：新玩家进入引导；错误：配置或存档异常分开提示，不覆盖旧档。
- 动画：纸张卷开 180ms，减少动态模式静态；广告位置：无。

## 02 主游戏页

- 目的：一眼知道收入、状态和下一行动；入口：启动成功及任意页返回；退出：底栏切页，Session 保留。
- 核心信息：境界、工资、绩效、修为、道心、KPI、办公室与 4×4 合成盘。
- 主要按钮：「招募牛马」；次要按钮：工作/摸鱼切换、KPI、任务/成就/设置。
- 状态：工作 / 摸鱼 / 道心不足 / 招募中 / 满盘；空：首个空槽提示招募；错误：招募失败 Toast 并恢复按钮。
- 动画：收入数字轻跳，背景低频摆动；广告位置：可选额外招募入口在独立奖励面板，常规招募永不伪装广告。

## 03 牛马合成区

- 目的：拖动同级角色合成；入口：主游戏中央；退出：松手或取消拖动，不切页。
- 核心信息：等级、可配对高亮、目标格；主要操作：拖到同级目标；次要操作：点卡看详情。
- 状态：空闲 / 拖动 / 合成锁定 / 无效目标 / 满级；空：空格绘制工位轮廓；错误：坐标失效、节点销毁或业务拒绝时返回权威位置。
- 动画：320ms 向 target 聚合，source 清空；只有业务成功才播放；广告位置：自动合成候选在奖励弹窗，不覆盖拖拽热区。

## 04 职业/境界页

- 目的：解释成长路线和晋升门槛；入口：职业底栏或境界徽章；退出：返回牛马页。
- 信息：真实 career 名称、当前境界、下一档门槛、倍率来源；主要按钮：「准备答辩」；次要：「查看 KPI」、成长路径。
- 状态：未达标 / 可晋升 / 顶级 / 答辩中；空：无下一档显示「已达当前上限」；错误：配置读取失败禁用晋升并可重试。
- 动画：路径节点点亮 240ms；广告位置：本页无强制广告，失败后的重试在答辩弹窗。

## 05 KPI 页面

- 目的：把条件变成可行动目标；入口：HUD 的 KPI 进度；退出：关闭或返回主页面。
- 信息：每项真实进度/目标、已完成项数、统计口径；主按钮：「去完成」跳相应页；次按钮：「查看晋升」。
- 状态：进行 / 达标 / 顶级 / 刷新中；空：无 KPI 显示「本阶段暂无考核」；错误：目标缺失显示“—”而非已完成。
- 动画：进度条 240ms、完成印章 280ms；广告位置：无，不能以看广告跳过 KPI。

## 06 办公室事件弹窗

- 目的：短笑点与明确取舍；入口：服务产生 pending event 或事件底栏；退出：处理成功关闭；可暂收起但不丢 pending。
- 信息：标题、1–2句、类别、每项收益/代价；主按钮：2–3个选项或「收下/知道了」；次按钮：「稍后处理」。
- 状态：待选 / 处理中 / 已处理；空：事件页「今日工位风平浪静」；错误：选择失败保留 pending 与选项，不重抽。
- 动画：纸条滑入 180ms；广告位置：Event Reroll 单独确认，服务无能力时不展示。

## 07 晋升答辩弹窗

- 目的：知晓条件、概率及结果；入口：职业页达标操作；退出：未提交可关闭，结果确认返回职业。
- 信息：概率、成本、方案及失败结果；主按钮：「开始答辩」；次：「再准备一下」，失败后可选「看广告再试一次」。
- 状态：准备 / BUSY / 成功 / 失败 / 已用重试；空：无方案禁用主按钮；错误：交易失败不自行扣费、升级或回滚。
- 动画：900ms KPI 天书盖章，结果由服务决定；广告位置：仅失败后的 Promotion Retry，默认有「返回修炼」。

## 08 离线收益弹窗

- 目的：展示离线预览并选择结算；入口：服务返回离线预览；退出：「收下」对未结算实体调用claimNormal，对已结算实体仅确认展示。
- 信息：离线时长/有效时长/封顶原因、基础收益、广告成功总收益；主按钮：「收下」；次：「看广告 ×2」。
- 状态：未结算 / 广告中 / 已结算1倍 / 已结算2倍 / 已确认；空：零收益不自动弹；错误：广告失败保留普通领取入口，不伪发追加。
- 动画：工资条展开180ms，入账一次；广告位置：Offline Double，按settlementId去重。当前服务1倍/2倍互斥，已领1倍不能再追加；禁止UI自行补差额。

## 09 成就页

- 目的：长期目标与梗收藏；入口：右侧成就；退出：返回牛马。
- 信息：分组、未达成/可领/已领；主按钮：「领取」；次：分类筛选。
- 状态：LOCKED / COMPLETED / CLAIMED；空：「新的传说，等你打卡」；错误：领取失败保持服务状态，可重试。
- 隐藏成就：达成前显示「??? / 还有传说没被发现」，不显示条件和图标剧透。
- 动画：解锁小章 280ms；广告位置：无，不用广告解锁或追加同一成就奖励。

## 10 每日任务页

- 目的：短时游玩方向；入口：右侧任务；退出：返回牛马。
- 信息：今日清单、进度、奖励、明确刷新倒计时；主按钮：「领取」或「去完成」；次：「查看规则」。
- 状态：进行 / 可领 / 已领 / 跨日刷新；空：「今日清单已收工」；错误：时间或任务数据异常禁用领取并说明。
- 动画：完成打勾 220ms；广告位置：无，正常任务不以广告代替操作。每日随机候选未实现，当前仍显示真实服务清单。

## 11 宗门/公司页

- 目的：展示公司类型与加成取舍；入口：宗门底栏；退出：返回主游戏。
- 信息：PRIVATE/FOREIGN/STATE/BIG_TECH 的真实名称与倍率；主按钮：「选择公司」；次：「查看加成」。
- 状态：未选 / 已选 / 不可更换 / 提交中；空：「散修也能准点下班」；错误：服务拒绝时保留旧选择。
- 动画：工牌翻面 240ms；广告位置：无。不新增宗门联机、贡献、商店。

## 12 设置页

- 目的：声音、减少动态与问题说明；入口：右侧设置；退出：返回/关闭。
- 信息：音效/BGM 开关、版本、存档状态；主操作：开关；次：「帮助」「隐私说明」。
- 状态：读取 / 可用 / 保存设置中；空：无存档状态显示“未获取”；错误：设置存储失败提示重试，不影响业务存档。
- 动画：开关 120ms；广告位置：无。清档只在 DEV Debug，不把危险操作放生产常规按钮。

## 13 新手 Overlay

- 目的：一步一个动作；入口：TutorialService 的当前步骤；退出：完成或允许的跳过。
- 信息：单句说明、目标高亮、步骤；主要操作：真实目标控件；次：「稍后学习」（服务允许时）。
- 状态：等待目标 / 引导 / 操作中 / 完成；空：无步骤不显示；错误：目标不存在关闭遮罩并报告，不锁死页面。
- 动画：指针 600ms 轻摆，减少动态用静态箭头；广告位置：无，引导不能诱导点击广告。

## 14 奖励广告弹窗

- 目的：清楚说明广告换什么；入口：明确标“看广告”的奖励位；退出：取消始终可用，平台播放期间交给平台控制。
- 信息：奖励、次数、成功条件；主按钮：「看广告 + 明确奖励」；次：「不用了」。
- 状态：不可用 / READY / 请求中 / 播放中 / 发奖中 / 已领取 / 失败；空：无可用广告显示「暂时没有广告」；错误：保留普通玩法、不发奖、清理 loading。
- 动画：普通 Modal，无自动播放；广告位置：本弹窗唯一用途，不增加插屏。

## 15 Debug 页（仅 DEV）

- 目的：诊断，不作为产品主页；入口：开发构建的显式 DEV 菜单；退出：返回，销毁诊断订阅。
- 信息：只读 Session/事件/帧率概要、版本；主按钮：「复制诊断摘要」；次：带二次确认的测试操作。
- 状态：DEV 可用 / release 完全不注册路由；空：「暂无诊断记录」；错误：数据读取失败不影响游戏。
- 动画：无；广告位置：无。禁止展示 token、用户身份或完整存档个人数据。
