# UI State Matrix

各单元格是具体设计响应，不是已有功能或测试通过声明。N/A表示该组件不拥有这种状态，解释在表后；不能用N/A掩盖请求挂起。适用于未来同Session只读VM。

缩写：L=loading，N=normal，D=disabled，E=empty，C=claimable，G=claimed，X=error，O=offline，A=ad unavailable，M=max level，F=full board，I=insufficient resource。

N/A原因：合成/KPI/晋升/教程/设置不属于领取奖励事务（C/G）；KPI/成就/每日/教程/设置不发起广告（A）；Promotion/Offline/成就/设置不消费棋盘格（F），只有关联入口受能力影响；Board不花资源（I，当前免费招募不能捏造不足工资）；Offline/成就/设置无资源门槛（I）；Offline/Settings没有等级上限语义（M）。

O区分网络离线与APP后台：网络离线可继续本地玩法，APP后台统一暂停交互/视觉并交Session生命周期处理，不代表回放事件或重复结算。C不能由静态文案推导；G必须服务提交确认。多状态优先级：失效/销毁 > 交易中 > error > unavailable > loading > 普通展示；error不覆盖已确认入账，晚到旧结果按requestId丢弃视觉。

验收：每非N/A格至少一夹具，每个组件一次bind→disable→bind→destroy路径；关键交易双击、跨日、后台恢复与重复回调。当前为定义矩阵，未声称Cocos实现通过。
