# V10.1 游戏设计（GAME_DESIGN）

> 基准：现有代码为准的增量设计记录。不推翻 V10 已定玩法；记录 V10.1 增量决策与下一阶段设计意向。

## 1. 核心循环（已定，V10 保持）

```
上线 → 领离线收益（可选看广告×2）→ 处理破事（事件/决策）
  → 推关战斗（自动+点击，Boss 关卡牌战）→ 招募/升级/装备 → 挂机/摸鱼/修炼分配
  → 下线（pagehide 存档）→ 离线托管（策略：均衡/稳健/卷王/摸鱼）
```

## 2. V10.1 设计决策记录

### 2.1 离线双倍领取（本轮新增 UI）
- **决策**：广告入口接在「欢迎回来·离线工作简报」而非复活孤立的 showOfflinePopup——简报是唯一可达启动流，且信息更全（托管策略/决策队列）。
- **视觉层级**：金色（📺 看广告 ×2）在上 = 增益注意力；蓝色（继续上班）在下 = 保底动作。符合「金色修仙装饰 + 深蓝主视觉」规范。
- **失败语义**（与 Cocos OFFLINE_REWARD 弹窗统一）：广告未完成 → 回落普通领取，玩家永不空手；取消 → 不发放 + 重建简报。
- **防重**：服务层三重守卫不动（isSettled / claimedDoubleSettlementIds / claimingSettlementId + 异步后二次校验）。

### 2.2 一键推荐装备（本轮新增）
- **评分公式**：`score = atk × (1 + critRate × critMult) × 2 + hp`
  - atk 权重 ×2：战斗 DPS 是推关第一资源；暴击期望加权只影响 atk 项（武器高暴击特性保留价值）
  - hp 直接累加：护甲槽位（纯 hp 线）与武器可同尺度比较
- **槽位独立**：4 槽（WEAPON/ARMOR/ACCESSORY/RELIC）互不影响，逐槽取最优即全局最优（无套装冲突时）。
- **幂等**：已是最优配置 → 零换装 + 提示；重复点击无副作用。
- **注意**：掉落自动穿空槽 → 「更强装备落背包」场景出现在 stage≥8（静电容键盘）后；推荐按钮的真实价值期在中前期。

### 2.3 NPC 关系增益可视化（本轮新增）
- 设计动机：关系驱动增益（§47）代码存在但玩家不可见 → 「好感度有什么用」认知断裂。
- 呈现：人际页顶部增益卡（6 行：NPC 名 + 效果名 + 实时数值），好=绿/坏=红/中性=灰。
- 教学文案：'维护好关键人脉就是维护修炼资源'。

## 3. 设计意向（未实施，见 BACKLOG）

### 3.1 职级 10 → 20 级
- 曲线（rpg 技能口径）：`requiredExp(L) = requiredExp(10) × 1.6^(L-10)`，晋升答辩在 13/16/19 加密；薪资乘子 ×1.25/级 递延。
- 命名延续职场修仙双语梗（例：任务书 20 级清单 → 11 实习组长 / 14 正式项目经理 / 17 部门总监 / 20 区域副总裁）。
- progression.json 后 4 级重复名必须先修复。

### 3.2 功法流派
- route ∈ {WORK, FISH, CULTIVATE, SOCIAL}，每路线 3 功法（现有 8 个归类 + 补 4 个）。
- 同 route 装备 2 个激活「流派共鸣」（复用 v64 羁绊模式：Bug 追踪/稳定发布先例）。

### 3.3 境界系统
- 境界表独立于职级：练气/筑基/金丹/元婴/化神/渡劫 × 初中后层。
- 突破消耗修为 + 心神；失败掉心境（复用 promotionFailCount 模式）；境界提供全局乘子槽位。

## 4. 数值红线（不破坏项）
- 灵石经济闭环：50×slot² 招募 / 20×lv² 点击升级 / 宝箱 (stage×7+3)%4 / 章节 Boss +40~66
- 敌人 HP 曲线 50×1.13^(n-1)；小 Boss +2/关
