# V11 游戏设计现状索引（GAME_DESIGN）

> 本文件是「设计现状 + V11–V15 扩展方向」的单一索引。深度规格以既有权威文档为准（不重复）。

## 核心循环（现状，全部有实现）

```
工作/摸鱼（work-service 六模式） → 工资+绩效+KPI → 晋升答辩（概率制+IAA重试）
→ 随机职场事件（30+事件池/资格契约） → 灵石+修为 → 修炼（暴击/连击/心境）
→ 功法五路线（WORK/FISH/CULTIVATE/SOCIAL/ADAPTIVE，3 槽+共鸣） → 装备强化（MAX10）
→ 卡牌战斗（v59o 种子引擎+Boss） → 合成（merge+craft 炼丹） → NPC 社交（好感/记忆/传书）
→ 离线结算（分段+封顶+exactly-once） → 存档（v15 fail-closed）
```

职场与修仙的互相牵制：摸鱼 salaryMul 0.6 / cultivationMul 1.1 / mindPerHour 40（work-service.ts:43）——工作收益高但道心降、摸鱼修为快但工资低。

## V11 新增玩法面

- **炼丹品质博弈**：成功率 75–95% × 品质权重（普通/良品/上品/极品 ×1/1.3/1.7/2.5），修为→修为配方 EV 仍净负（消耗池定位），失败消耗材料——风险决策而非无脑点击；
- **炼丹成就线**：初试丹道→丹道入门→小成→制药大亨 + 极品丹师（稀有追逐）+ 百炼成丹（失败安慰，幽默调性）；
- **排行榜四维**：职级/修为/财富/成就榜，NPC 带随玩家缩放（前期不碾压、后期不垫底）。

| 系统 | 设计要点（先立 ADR 再动工） |
|---|---|
| 境界独立系统（B1） | 炼气→渡劫十境×小层；突破材料/成功率/失败代价；与晋升答辩联动（职场境界双轨）；**需存档 v16 迁移** |
