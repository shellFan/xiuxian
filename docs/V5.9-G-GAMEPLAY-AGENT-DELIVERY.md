## 交付内容

GamePlay Agent 已作为仓库基础设施集成在 `ai/gameplay-agent/`，根目录 `package.json` 提供 smoke、完整测试、报告、失败复测和发布 gate 命令。主说明和场景/报告格式见 [`ai/gameplay-agent/README.md`](../ai/gameplay-agent/README.md) 与 [`docs/GAMEPLAY-AGENT.md`](GAMEPLAY-AGENT.md)。场景变量由 Node Runner 管理，按场景和显式 run 作用域隔离，支持类型约束、缺失值错误，并跨 renderer 刷新及 EXE 重启保留。

交互检查使用真实 CDP 鼠标、键盘和滚轮事件。对滚动裁剪的控件，Runner 求出控件与可见滚动区域的交集，再在有效区域内做 hit-test 和点击；完全裁剪、越界或被弹窗遮挡时会拒绝点击。随机事件通过实际指针点击其关闭/确认按钮，等待关闭并验证目标解除遮挡后才继续；最多尝试三次。失败证据包含弹窗前后 DOM、按钮、Canvas、裁剪/命中位置、操作尝试、控制台消息、EXE 日志和 renderer 截图。

场景读取已有 `GameFacade`、时钟、经济、任务和存档服务，没有另建工资、钱包或游戏时钟。测试使用每场景独立临时 Electron 存档。发布包关闭测试桥接；Agent 只连接本次启动 EXE 的 localhost CDP 端口。

## 重复运行

```powershell
npm test
npm run pc:build
npm run pc:pack
npm run pc:check
npm run gameplay-agent:smoke
npm run gameplay-agent:test
npm run gameplay-agent:report
npm run gameplay-agent:gate
```

发生失败后先看 `gameplay-agent:report` 和对应 `reports/<run-id>/` 证据，修复后运行 `gameplay-agent:rerun-failed`。每个缺陷最多自动计入三轮复测；达到上限会写出 `ESCALATED-<run-id>.json`。
